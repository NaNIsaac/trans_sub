# trans_sub

Moved into a private scratch repo; no longer maintained.

Skeleton project for working with `.srt` subtitle files.

Only the project setup exists so far: `main.py` imports the `srt` package and prints a greeting. There is no subtitle parsing or translation code yet.

## Usage

Requires Python 3.13 and [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/NaNIsaac/trans_sub.git
cd trans_sub
uv run main.py
```
